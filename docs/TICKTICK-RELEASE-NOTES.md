# TickTick Product Release Notes — Capability Index & Structured Plan

**Purpose:** Give an LLM (or product/engineering team) a crisp, complete map of TickTick's capabilities so it can plan, compare, or rebuild the product without re-reading documentation.

**Method:** Every capability uses the **Speed-Read Dummies Framework** — a four-line block that answers the only questions that matter.

---

## How to read this file

For every capability:

- **In one line** — the shortest possible explanation.
- **What it does** — the observable behavior, no fluff.
- **Why it matters** — the user outcome it unlocks.
- **Speed-read** — a single sentence an LLM can consume instantly.

Use the **Capability Matrix** first to get the map, then drill into the blocks you need.

## Capability Blocks

### 1. Quick Capture
- **In one line:** Capture a task in the fewest possible actions.
- **What it does:** Adds tasks instantly from widget, shortcut, browser, email, or app.
- **Why it matters:** Reduces the friction between thought and recorded task.
- **Speed-read:** Fast task entry so nothing is forgotten.

### 2. Natural Language Input (NLP)
- **In one line:** Type a task naturally and TickTick parses it.
- **What it does:** Detects dates, times, and recurrences from plain text like "call John tomorrow 3pm."
- **Why it matters:** Eliminates manual field filling.
- **Speed-read:** Human language becomes structured task data.

### 3. Voice Input
- **In one line:** Speak a task and it becomes text.
- **What it does:** Converts voice to a written task entry.
- **Why it matters:** Supports hands-free capture.
- **Speed-read:** Voice-to-task capture.

### 4. Widgets
- **In one line:** Home-screen widget for viewing and adding tasks.
- **What it does:** Displays task list and allows quick add without opening the app.
- **Why it matters:** Keeps tasks visible and one tap away.
- **Speed-read:** Home-screen task access.

### 5. Global Shortcut
- **In one line:** A system-wide hotkey opens a task entry box.
- **What it does:** Adds a task from any application.
- **Why it matters:** Captures ideas without context switching.
- **Speed-read:** Anywhere-to-task hotkey.

### 6. Browser / Email Capture
- **In one line:** Turn browser text or email into tasks.
- **What it does:** Uses browser extension or email plugin to create tasks from selected content.
- **Why it matters:** Ingests tasks from existing workflows.
- **Speed-read:** External content becomes tasks.

### 7. Lists
- **In one line:** Containers that group related tasks.
- **What it does:** Organizes tasks into named lists.
- **Why it matters:** Separates life areas (work, personal, projects).
- **Speed-read:** Named task containers.

### 8. Tags
- **In one line:** Lightweight labels that cut across lists.
- **What it does:** Adds reusable labels for filtering and grouping.
- **Why it matters:** Enables flexible, non-hierarchical organization.
- **Speed-read:** Cross-list task labels.

### 9. Smart Filters
- **In one line:** Saved searches built from rules.
- **What it does:** Auto-collects tasks matching criteria (tag, list, date, priority).
- **Why it matters:** Keeps a focused view without manual upkeep.
- **Speed-read:** Rule-based auto-lists.

### 10. Priorities
- **In one line:** Mark tasks by importance.
- **What it does:** Assigns priority levels (usually none/low/medium/high).
- **Why it matters:** Surfaces what should be done first.
- **Speed-read:** Task importance ranking.

### 11. Subtasks
- **In one line:** Smaller steps inside a task.
- **What it does:** Nests child tasks under a parent task.
- **Why it matters:** Breaks complex work into actionable pieces.
- **Speed-read:** Hierarchical task breakdown.

### 12. Notes & Attachments
- **In one line:** Context attached to a task.
- **What it does:** Stores descriptions, images, files, and details.
- **Why it matters:** Keeps everything needed for the task in one place.
- **Speed-read:** Task context storage.

### 13. Markdown / Rich Text
- **In one line:** Format task details with text styling.
- **What it does:** Supports Markdown for headers, lists, links, and formatting.
- **Why it matters:** Makes task notes readable and structured.
- **Speed-read:** Rich formatting in task details.

### 14. Reminders
- **In one line:** Alerts at a chosen time.
- **What it does:** Sends notification before or at due time; supports multiple alerts.
- **Why it matters:** Prevents missed deadlines.
- **Speed-read:** Time-based task alerts.

### 15. Recurring Tasks
- **In one line:** Tasks that repeat automatically.
- **What it does:** Repeats daily, weekly, monthly, yearly, or custom schedules.
- **Why it matters:** Maintains routines without re-creating tasks.
- **Speed-read:** Auto-repeating tasks.

### 16. Constant Reminder
- **In one line:** Keeps notifying until the task is completed.
- **What it does:** Repeats alerts so an important task is not dismissed.
- **Why it matters:** Escalates high-priority items.
- **Speed-read:** Persistent task nagging.

### 17. Location Reminder

## Structured Release Plan

The plan is divided into **Release Waves** so an LLM can sequence work without ambiguity.

### Wave 1 — Core Capture & Task Foundation
**Goal:** A user can capture, organize, and complete basic tasks.

- Quick Capture
- Natural Language Input
- Lists
- Tags
- Priorities
- Subtasks
- Notes & Attachments
- Reminders
- Recurring Tasks
- Smart Lists

**Exit condition:** Create → organize → remind → complete works end to end.

---

### Wave 2 — Scheduling & Calendar
**Goal:** Tasks become time-aware.

- Calendar Views
- Google Calendar Sync
- Time Blocking
- Time Zone
- Countdown

**Exit condition:** A user can place tasks on a calendar and see external events.

---

### Wave 3 — Focus & Productivity Rituals
**Goal:** Users can protect time and build habits.

- Pomodoro Timer
- Habit Tracker
- Eisenhower Matrix
- Daily Reminder
- Statistics

**Exit condition:** A user can run a focus session, log a habit, and see progress.

---

### Wave 4 — Advanced Organization & Collaboration
**Goal:** Power users and teams can manage complex work.

- Kanban View
- Timeline View
- Smart Filters
- Collaboration
- Keyboard Shortcuts
- Markdown / Rich Text

**Exit condition:** Shared lists, boards, and advanced filtering work.

---

### Wave 5 — Personalization & Integrations
**Goal:** The app feels personal and fits existing tools.

- Themes
- List Backgrounds
- Voice Input
- Widgets
- Global Shortcut
- Browser / Email Capture
- Notion Integration
- Third-Party Integrations
- Location Reminder
- Constant Reminder
- Email Reminder
- Cross-Platform Sync

**Exit condition:** Users can customize and connect TickTick to their stack.

## Release Notes Copy (customer-facing, concise)

**TickTick brings tasks, calendar, habits, and focus into one quiet system.**

- **Capture faster.** Add tasks with natural language, voice, widgets, or a global shortcut.
- **Stay organized.** Lists, tags, smart filters, priorities, and subtasks keep everything in place.
- **Never miss a beat.** Time, recurring, location, email, and constant reminders cover every context.
- **See your day.** Yearly to multi-week calendar views, Google Calendar sync, and time blocking make schedules visible.
- **Do the work.** Kanban, timeline, and three-pane list views match any workflow.
- **Build momentum.** Habit tracking, Pomodoro, and the Eisenhower Matrix turn plans into progress.
- **Make it yours.** 40+ themes, list backgrounds, time zones, and cross-platform sync adapt to the user.
- **Bring your stack.** Share lists, assign tasks, and integrate with Notion and other tools.
